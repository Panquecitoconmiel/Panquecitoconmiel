## 🌸 Sobre mí

Soy **Ingeniera en Desarrollo y Gestión de Software** con un promedio de **9.7/10** 🎓.

Me especializo en el desarrollo de aplicaciones web y móviles, combinando **programación, diseño de interfaces y organización de proyectos** para construir soluciones digitales funcionales y bien estructuradas.

Me gusta involucrarme en todo el proceso de desarrollo de un producto:

> 💡 Idea → 🎨 Diseño → 🧩 Arquitectura → 💻 Desarrollo → 🚀 Implementación

Actualmente trabajo principalmente con **React y Laravel**, y continúo fortaleciendo mis conocimientos en **arquitectura de software y seguridad informática**.

También cuento con experiencia trabajando directamente con clientes en proyectos freelance de **desarrollo web, branding, diseño y creación de sitios digitales**.

Cuando el código descansa, escribo relatos ✍️
